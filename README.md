# Analyse de données sous tableur

Projet universitaire (Licence Informatique, Université de Limoges, décembre 2025), réalisé en binôme avec Ali Rachid.

## Ma partie : exercices 2 et 3

### Ventes de jeux vidéo
- Import et structuration d'un fichier CSV de plus de 64 000 lignes
- Jeu le plus vendu trouvé automatiquement (INDEX / EQUIV)
- Pourcentage de jeux sans note critique (NB.SI)
- Région la plus lucrative pour chaque jeu
- Score pondéré (note × ventes) comparé à la moyenne
- Moyenne des ventes par genre (MOYENNE.SI)

### Attaques de requins
- Tableaux croisés dynamiques (année × type d'attaque)
- Graphiques pour dégager des tendances sur le long terme
